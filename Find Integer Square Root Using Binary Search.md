# ✨ **Find Integer Square Root Using Binary Search** ✨

**Description:**
This PR adds a Python implementation of the `mySqrt` function, which calculates the **integer part of the square root** of a non-negative number using the efficient **binary search** technique. This is a classic algorithmic problem frequently asked in interviews and coding contests.


**Details:**
- Implemented `mySqrt` method under a `Solution` class.
- Uses binary search to find the largest integer `mid` such that `mid² ≤ x`.
- Efficiently handles edge cases for inputs less than 2.
- Avoids built-in square root functions to stick to algorithmic logic.

**Why this is a valuable addition:**
- A classic use-case of binary search in numerical computation.
- Offers a clean and performant alternative to `math.sqrt()` for integer results.
- Reinforces understanding of search space reduction and loop invariants.
- Perfect fit for the repository’s goal: concise, high-value Python code under 100 lines.
